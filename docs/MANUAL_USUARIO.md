# MANUAL DE USUARIO — YeferTasks v1.1

## 1. Bienvenida

### ¿Qué es YeferTasks?
YeferTasks es una aplicación móvil diseñada para ayudarte a organizar tus pagos, tareas e ingresos de manera sencilla y eficiente. Con una interfaz intuitiva y notificaciones inteligentes, nunca más olvidarás un vencimiento importante.

### ¿Para qué sirve?
- **Organizar pagos**: Arriendo, servicios, tarjetas de crédito y más.
- **Gestionar tareas**: Renovaciones, trámites y pendientes personales.
- **Controlar ingresos**: Lleva un registro de lo que debes y lo que ya pagaste.
- **Recibir recordatorios**: Notificaciones personalizadas para que estés siempre al día.

## 2. Primeros Pasos

### Instalación en Android
1. **Descargar el APK**: Ve a [GitHub Releases](https://github.com/yeferherrera/Yefer-Tasks/releases) y descarga la última versión del APK.
2. **Activar instalación de apps desconocidas**:
   - Ve a *Ajustes* > *Seguridad* > *Orígenes desconocidos*.
   - Activa la opción para permitir instalaciones desde tu navegador o explorador de archivos.
3. **Instalar**:
   - Abre el archivo APK descargado.
   - Sigue las instrucciones en pantalla.
   - ¡Listo! Ya tienes YeferTasks instalado.

### Crear una cuenta
1. Abre la aplicación YeferTasks.
2. Toca el botón **"Regístrate"** en la pantalla de inicio.
3. Escribe tu correo electrónico y una contraseña segura.
4. Confirma tu registro.
5. ¡Ya eres parte de YeferTasks!

### Iniciar sesión
1. Abre YeferTasks.
2. Escribe tu correo electrónico y contraseña.
3. Toca **"Iniciar sesión"**.
4. ¡Bienvenido! Tu información está segura en la nube.

## 3. Pantalla Principal (Inicio)

### Encabezado
- **Logo**: YeferTasks aparece en la parte superior.
- **Saludo**: Un "Hola 👋" personalizado para ti.

### Alerta de mora
- Si tienes pagos vencidos, aparecerá una **alerta roja** con el número de pendientes en mora.
- Toca la alerta para ver los detalles y evitar recargos.

### Resumen mensual
- **Total deudas**: Cuánto debes este mes.
- **Pagado**: Cuánto ya has liquidado.
- **Restante**: Lo que falta por pagar.
- **Barra de progreso**: Visualiza tu avance de pago.

### Filtros por módulo
- **Todos**: Muestra todos los pendientes (excluye pagados).
- **Por pagar**: Pagos próximos a vencer.
- **En mora**: Pagos vencidos (resaltados en rojo).
- **Pagados**: Elementos completados (en verde).
- Cada filtro tiene un **badge** con el conteo de elementos.

### Pull-to-refresh
- Desliza hacia abajo en la pantalla para actualizar la información.

---

## 4. Crear un Pago o Tarea

1. Toca el botón **"+"** (abajo a la derecha).
2. Selecciona el tipo:
   - 💳 **Pago**: Para deudas con valor en pesos.
   - 📝 **Tarea**: Para pendientes sin valor monetario.
3. Llena los campos:
   - **Título** (obligatorio): Ej. "Arriendo", "Internet".
   - **Valor en pesos** (solo pagos): Ej. 850000.
   - **Fecha límite**: Usa el calendario para seleccionar la fecha.
   - **Hora del recordatorio**: Formato HH:mm, Ej. 09:00.
   - **Recurrente** (cada mes): Activa si se repite mensualmente.
   - **Notas** (opcional): Agrega detalles adicionales.
4. Toca **"Guardar"**.

---

## 5. Marcar como Completado

1. Toca el **círculo (✓)** en la tarjeta del item.
2. Aparece una confirmación: *"¿Estás seguro?"*
3. Toca **"Completar"**.
4. El item se marca con un **check verde**.
5. Aparece un botón **"Editar"** para hacer cambios.
6. Si el item es **recurrente**, se crea automáticamente el próximo mes.

---

## 6. Editar o Eliminar

### Editar
- Toca la **tarjeta** o el botón **"Editar"**.
- Modifica los campos necesarios.
- Toca **"Guardar cambios"**.

### Eliminar
- Dentro de la pantalla de edición, toca **"🗑 Eliminar"**.
- Confirma la eliminación.
- El item y sus recordatorios se borraran permanentemente.

---

## 7. Selección Múltiple

1. **Mantén presionada** una tarjeta para activar el modo selección.
2. Toca otras tarrellas para seleccionarlas.
3. La **barra superior** muestra:
   - Cantidad de elementos seleccionados.
   - Botón **"❌"** para cancelar la selección.
   - Botón **"🗑"** para eliminar todos los seleccionados de una vez.
4. Confirma la eliminación.

---

## 8. Calendario

### Visualización
- **Marcadores de colores** por día:
  - 🔵 **Azul**: Pagos programados.
  - 🟢 **Verde**: Tareas programadas.
  - 🔴 **Rojo**: Pagos vencidos.
  - 🟩 **Verde claro**: Pagados.
- Toca un día para ver sus items pendientes.
- Navega entre meses usando las flechas.

### Leyenda
- Los puntos indican días con pendientes.
- Colores corresponden a los tipos de item y su estado.

---

## 9. Balance

### Resumen mensual
- **Total deudas del mes**: Suma de todos los pagos.
- **Cuánto pagaste**: Monto total pagado.
- **Cuánto falta**: Saldo pendiente.
- **Barra de progreso**: Porcentaje completado.

### Gráfica de barras
- **Verde**: Pagado.
- **Rojo**: Vencido.
- **Violeta**: Pendiente.
- Navega entre meses con las **flechas ← →**.

### Lista de pendientes
- Muestra todos los pagos del mes que aún no se han completado.
- Toca un item para marcarlo como pagado o editarlo.

### Perfil

### Notificaciones personalizadas

## 12. Consejos de Uso

1. **Marca como recurrente** los pagos que se repiten cada mes (arriendo, servicios).
2. **Usa el calendario** para visualizar la semana y planificar pagos.
3. **Revisa el balance** semanalmente para controlar tus gastos.
4. **Activa el resumen matutino** para comenzar el día informado.
5. **Usa la selección múltiple** para eliminar varios elementos a la vez.
6. **Configura la ventana flotante** si necesitas ver pendientes rápidamente.

## 13. Preguntas Frecuentes

### ¿Mis datos están seguros?
**Sí**, todos los datos se almacenan en **Firebase** con reglas de seguridad avanzada. Tu información está protegida.

### ¿Funciona sin internet?
- Las **notificaciones** sí funcionan sin conexión.
- Los **datos** necesitan internet para sincronizarse.

### ¿Cómo cambio mi contraseña?
Desde la configuración de **Firebase Auth** en tu cuenta de Google. YeferTasks no gestiona contraseñas directamente.

### ¿Puedo usar en iOS?
**Sí**, el código es compatible con iOS. Puede requerir ajustes menores para compilación en Xcode.
